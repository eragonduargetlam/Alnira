# Layer 2: Stillmere
tags: [layer-2, stillmere, node-map]

## Overview
[[Stillmere]] is the next day’s travel along the Old Trade Road.  
Two parallel story funnels continue from [[Briarhold]], each offering intrigue, hazards, and secrets.  
Sideways links connect nodes **within Stillmere**, but are logical follow-ups — clues the PCs could only notice after visiting the originating node.  
Forward links point to Layer 3 nodes leading toward Velcairn.

---

## Funnel A: Trade & Guild Tensions
- [[Lyd2Vel Node 1D - Smuggler’s Inn]] → forward: [[Lyd2Vel Node 1G - Outlaw Camp]]  
- [[Lyd2Vel Node 1E - Rival Caravan]] → forward: [[Lyd2Vel Node 1G - Outlaw Camp]]  
- [[Lyd2Vel Node 1F - River Ferry]] → forward: [[Lyd2Vel Node 1H - Abandoned Watchtower]]

**Sideways connections (follow-up logic):**  
- Smuggler’s Inn → Rival Caravan (patrons’ observations about cautious caravans)  
- Rival Caravan → River Ferry (guards mention secret river crossings seen earlier)  
- River Ferry → Smuggler’s Inn (logs note prior deliveries from the Inn)

**Theme:** Hidden trade, rival caravans, guild influence, and the risks of moving cargo in secret.  
**Tone:** Suspense, negotiation, and opportunism.

## Funnel B: Shadows & Secrets

- [[Lyd2Vel Node 2E - Cult Camp]] → forward: [[Lyd2Vel Node 2H - Abandoned Shrine]]

**Sideways connections (follow-up logic):**  
- Hidden Cult Cell → Cult Camp (cultist mentions supplies/rituals at marsh camp)  
- Cult Camp → Hidden Cult Cell (observed footprints and ritual traces)  
- Poisoned Caravan → Hidden Cult Cell (guards report recent cult activities along the road)

**Theme:** Old Gods remnants, cult secrecy, and creeping supernatural influence.  
**Tone:** Cryptic, eerie, conspiratorial.

## Navigation Notes
- PCs can visit nodes in any order; lateral clues provide follow-up information, not forced travel.  
- Forward clues naturally funnel the narrative to Layer 3 encounters and Velcairn approach. 
- Each node contains enough detail (NPCs, interactions, stakes, and flavor) to run as a self-contained encounter.
