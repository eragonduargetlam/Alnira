# Layer 1: Briarhold
tags: [layer-1, briarhold, node-map]

## Overview
[[Briarhold]] is the first settlement along the Old Trade Road east of [[Lydborough]].  
Two distinct story funnels branch from here, both pointing ultimately toward [[Velcairn]].  
The party can engage either (or both) depending on choices, pacing, and the Dawnbreaker Synod countdown.

---

## Funnel A: Trade & Guild Tensions
- [[Lyd2Vel Node 1A - Travelling Merchant]] → leads toward [[Lyd2Vel Node 1D - Smuggler’s Inn]] (Stillmere, Layer 2)
- [[Lyd2Vel Node 1B - Defaced Shrine]] → leads toward [[Lyd2Vel Node 1E - Rival Caravan]] (Stillmere, Layer 2)
- [[Lyd2Vel Node 1C - Gatekeepers]] → leads toward [[Lyd2Vel Node 1F - River Ferry]] (Stillmere, Layer 2)

**Theme:** Guild monopolies, corrupted faith, and civic tensions.  
**Tone:** Suspicion, bureaucracy, and moral compromises.

---

## Funnel B: Shadows & Secrets
- [[Lyd2Vel Node 2A - Hermit's Cave]] → leads toward [[Lyd2Vel Node 2D - Hidden Cult Cell]] (Stillmere, Layer 2)
- [[Lyd2Vel Node 2B- Crescent Ruins]] → leads toward [[Lyd2Vel Node 2E - Cult Camp]] (Stillmere, Layer 2)
- [[Lyd2Vel Node 2C - Drowned road]] → leads toward [[Lyd2Vel Node 2F - Poisoned Caravan]] (Stillmere, Layer 2)

**Theme:** Old Gods remnants, cult secrecy, and dangerous revelations.  
**Tone:** Cryptic, eerie, conspiratorial.

---

## Navigation
- **Sideways links** connect nodes within Briarhold.  
- **Forward links** connect to corresponding nodes in Stillmere (Layer 2).  
- Each node can be approached in any order; every path eventually funnels toward [[Velcairn]]
